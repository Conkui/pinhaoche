# 小程序 UI 规格

采用 WeUI 与 iOS HIG 的克制风格：浅灰背景、白色内容面、系统蓝主要操作、统一圆角、充足留白，不使用渐变、霓虹、复杂阴影或多重悬浮控件。底栏固定为“已打上 / 预打车 / 消息 / 我的”。

每页只有一个最显著 Primary Action：已打上和预打车卡片为“立即联系发布者”，发布页为“发布”，详情页依状态显示“加入”或“不再等人”。

已打上卡片的视觉顺序：`出发地 → 目的地`、立即联系、余位、车牌、剩余距离（必须附更新时间）。预打车卡片顺序：路线、出发时间、同行/余位、备注。地点选择器先列启用的预设地点，最后提供“自定义填写”；自定义字段不展示为公共常用地点。

所有列表必须提供加载、空态、失败重试和已满/过期状态；危险操作要求二次确认。聊天页显示发送中、已确认、失败可重试三种状态，失败重试复用原 `clientMsgId`。
