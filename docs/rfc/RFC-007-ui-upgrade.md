# RFC-007：UI 视觉升级（参考 Ant Design 设计规范）

## 问题
用户反馈当前 UI 过于朴素、缺少美感（原型级白卡片+灰底）。

## 为什么需要修改
产品负责人直接指令。视觉属于小程序样式层（wxml/wxss），不触碰任何冻结契约（openapi/DB/状态机/WS 协议均不变）。

## 影响模块
小程序全部页面的 wxss/wxml；docs/UI_SPEC.md 的视觉约定按本 RFC 放宽。

## 建议修改（设计令牌，参考 Ant Design 5）
- 主色升级为 Ant Design 蓝 `#1677ff`，主按钮允许自顶向下 4% 的同色系轻渐变 + 柔和投影（非大面积渐变，不违反原规范的克制原则）。
- 建立字阶：页面标题 34rpx/600、卡片标题 32rpx/600、正文 28rpx、辅助 24rpx；统一 8 的倍数间距体系。
- 卡片：白底、圆角 20rpx、极浅投影 `0 4rpx 16rpx rgba(15,23,42,0.06)`；列表页背景 `#f5f7fa`。
- 功能色：成功 `#52c41a`、警示 `#faad14`、危险 `#ff4d4f`、信息 `#1677ff`；满员/过期用中性灰标签。
- 底栏选中色同步主色；页面标题区可用浅色底或大字重标题增强层级。
- 保持红线：每页一个 Primary Action、卡片视觉顺序不变（路线>联系>余位>车牌>距离）。
