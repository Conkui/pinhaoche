# RFC-005：管理端地点 CRUD 接口

## 问题
地点只有管理员预设与用户自定义两种来源（规范 §2.2），管理员需要后台 CRUD + 排序 + 启停，但 openapi 是小程序客户端契约，不包含管理端接口。

## 为什么需要修改
无管理入口则预设地点库无法维护，小程序"无需发版即可显示"不成立。

## 影响模块
place、admin；小程序不受影响。

## 建议修改
后端内部提供 `/api/v1/admin/places` CRUD + 启停 + 排序，用 `X-Admin-Key` 请求头（配置项，非微信用户 token）保护，并写入 docs/UI_API_MAPPING.md 备查。不修改冻结的 openapi.yaml（它只描述小程序侧契约）。
