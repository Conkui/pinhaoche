# RFC-006：新增 POST /feedback 意见反馈（冻结后修订）

## 问题
用户要求增加意见反馈功能，入口放"我的"页（不与主功能抢位置）。冻结契约无此端点。

## 为什么需要修改
用户直接指令的产品功能；属于新增独立能力，不影响既有端点与 DTO。

## 影响模块
新增 `feedback` 数据表（Flyway V2__feedback.sql，符合"数据库只能通过 Flyway 修改"）；后端新增端点；小程序"我的"页加入口。

## 建议修改
`POST /api/v1/feedback`（登录态），请求 `{ content: string(1..500) }`，响应 204。匿名不可提交（防灌水）；V1 只存不审（admin 审核后续迭代）。状态：已由 Integration 评审接受并实现。
