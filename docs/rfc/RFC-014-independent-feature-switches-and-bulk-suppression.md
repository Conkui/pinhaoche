# RFC-014：独立的实时拼/找拼友开关与批量运营抑制

## 决议

- “实时拼”与“找拼友”是独立功能：前者控制 `BOOKED` 列表、进入“我已打上车”及导入发布；后者控制 `PREBOOK` 列表、进入预打车及发布。
- 两项均有各自的 enabled 状态和停用公告，默认开启；管理端必须展示准确的名称和影响范围。
- 管理端增加批量抑制：仅接收管理员在页面明确选中的 ride ID，最大 100 条，执行前二次确认。抑制是可审计的运营隐藏，不物理删除 Ride、聊天或用户数据。

## 物理清理边界

生产物理删除测试数据会影响订单、成员、会话、Outbox 及统计关联，必须另行确认具体数据范围、保留期、备份与恢复方案。本 RFC 不授权物理删除。

## 状态

Integration 已接受；已完成独立审查，并补齐“隐藏订单不得再加入、聊天或变更”的统一门禁与批量订单存在性校验。
